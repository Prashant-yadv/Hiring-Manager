## 📌 Project Overview

The **HR Hiring System** is a modern, end-to-end recruitment management platform designed to simplify and organize the hiring process for HR teams and hiring managers.

From **manpower planning** to **candidate onboarding**, the system centralizes all recruitment activities into a single, intuitive interface—reducing manual effort, improving transparency, and enabling **data-driven hiring decisions**.

This project demonstrates my ability to design **real-world HR tech solutions**, focusing on usability, workflow automation, and analytics.

---

## 🎯 Problem Statement

Traditional hiring processes often suffer from:

* Scattered candidate data
* Manual resume screening
* Lack of hiring insights
* Poor coordination between HR and hiring managers

The **HR Hiring System** solves these challenges by offering a unified, structured, and scalable recruitment platform.

## ⚙️ How to Run the Project Locally

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/Prashant-yadv/Hiring-Manager.git
cd Hiring-Manager
```

### 2️⃣ Install Dependencies

```bash
npm install
```

### 3️⃣ Start Development Server

```bash
npm run dev
```

### 4️⃣ Build for Production (Optional)

```bash
npm run build
npm start
```
